# Raw Macaulay2 exports (n = 8)

Original outputs from the SSRI 2026 computations, kept unmodified.

- Graph numbers follow `geng -c 8` order after filtering to non-bipartite, min degree >= 2,
  9–19 edges (6971 graphs). All 6861 CM graphs match this numbering.
- The 110 non-CM graphs (`NonCMHash8`) were not exported; they are recomputed in
  `data/derived/noncm8_results.txt`.
- Known glitch: in `task3_Hilbert_CM_all8.txt`, graph 3 has `NumEdges: 1` (true value 12).
- `triangleCounts8_backup.txt` is identical to `triangleCounts8.txt`.
